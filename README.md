# As-Built

Draw the plan for a program before it is built, then walk through what was actually built.

In construction, the *as-built drawings* record what really got built, kept next to the
original plans. As-Built does the same for code:

1. **Plan.** An agent drafts a flowchart of the program before any code exists. You
   reshape it by talking to the agent, and the page in your browser redraws as the chart changes.
2. **As built.** Once the code exists, the chart is rebuilt from the code itself and compared
   with the plan, with a note on why each part changed.
3. **Walkthrough.** Follow the path data takes through the program, with the lines it
   passes through highlighted.
